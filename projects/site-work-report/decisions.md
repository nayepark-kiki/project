# 확정 사항

## 2026-11-23
- 로그인: 작업자·관리자 같은 화면, 접속 코드만 입력. 업체 코드면 작업자, 관리자 코드면 관리자
- 접속 코드: 관리자가 현장 설정에서 업체명을 등록하면 6자리 코드 자동 발급(중복 없음), 재발급·삭제 가능
- 작업자 개인 단위 관리 없음. 업체 단위로 로그인
- 작업 보고 입력(행마다): 건물(동)·위치(층)·직종·인원·작업내용 필수, 고위험 작업사항·방지대책 선택
- 투입 장비(장비명·규격·대수)와 기타 작업사항은 보고 단위, 선택
- 작업 보고는 탭 방식. 작성 중인 탭이 가장 왼쪽, 다른 탭은 오른쪽에 쌓임
- 같은 업체 하루 여러 번 제출은 합치지 않고 쌓음
- 제출한 보고는 자정 전까지 수정·삭제 가능. 변경 이력은 필요해지면 추가
- 오늘 작업 현황: 공사일보 양식 순서(금일 작업 내용 → 기타 작업사항 → 금일 인원 현황 → 장비 투입 현황)
- 금일 작업 내용은 업체별로 묶고, 고위험·방지대책은 작업내용 칸 안을 행으로 나눠 표시
- 업체 보기 필터(전체·업체별). 요약 숫자와 장비 표는 현장 전체 기준
- 대시보드에서 제출 단위 구분 안 함
- 작업자 화면: '우리 업체 오늘 보고'(수정·삭제, 작업 보고 쓰기). 관리자 화면: 현장 설정 메뉴, 엑셀 내려받기
- 엑셀은 공사일보 양식 그대로
- 누계는 서비스 시작일부터
- 반응형 기준 768px
- 작업 보고 상단에 업체명 표시 안 함. 화면 상단 부제는 현장명만

## 2026-11-24
- 오늘 작업 현황 모바일: 금일 작업 내용을 업체별 카드 안의 표로 표시. 왼쪽 동 칸 세로 병합, 오른쪽에 층·직종·인원·작업내용을 한 줄씩, 고위험이 있으면 고위험·방지대책 줄 추가
- 제출한 보고 목록에서 제출 시간 표시 삭제. 보고는 '동 직종 외 n건'으로 표시 (작업 보고·오늘 작업 현황 공통)
- 작업 보고: 공통 헤더와 작업 탭을 화면 상단에 고정 (PC·모바일)
- '우리 업체 오늘 보고' 제목 17px (작업 보고의 카드 제목과 같은 크기)
