# 공사현장 작업 보고 웹

## 목적
- 협력업체 작업 보고를 카톡 대신 웹으로 받음
- 관리자는 오늘 보고를 공사일보 양식 순서로 확인하고, 별도 공사일보 입력 웹페이지에 복사·붙여넣기 함

## 범위 (MVP)
- 로그인(작업자·관리자 공통, 접속 코드), 작업 보고, 오늘 작업 현황(작업자·관리자 화면 구분), 현장 설정
- 한 현장에서만 테스트
- 제외: 여러 현장 관리, 동별 배치도 시각화, 도면 AI 인식·배치도 편집, 수정·삭제 이력

## 키워드
- 공사현장, 작업 보고, 공사일보, 현장 작업 보고, 협력업체 보고
